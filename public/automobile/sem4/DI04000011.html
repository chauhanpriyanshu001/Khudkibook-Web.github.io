Software Engineering Syllabus — Unit-wise Content

The official GTU curriculum for Software Engineering (subject code DI04000011) as prescribed for Auto · Semester 4 divides the course into 4 units, covering 43 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (DI04000011)

Unit 1 Software Process Models

11 lecture hours

  • Defining software
  • Software Application Domain- System Software
  • Application Software
  • Embedded Software
  • Web Application
  • Artificial Intelligence Software and Green Hydrogen Ecosystem Software – Role of software in hydrogen production & distribution
  • Software Engineering – A layered Approach
  • Generic Process Model
  • Generic Framework Activity
  • Umbrella activity
  • Software Development Models- a) Traditional models - Waterfall model
  • Incremental process model
  • Prototype model
  • Spiral model
  • V- model b) Agile Approach - Principles of Agile
  • Agile Frameworks - Scrum
  • Extreme Programming (XP)

Unit 2 Software Requirement Analysis and Design

15 lecture hours

  • Requirement Gathering and Analysis - Types of Requirements (Functional and Non-functional)
  • Techniques for Requirement Gathering Software Requirement Specification (SRS) - Characteristics of a Good SRS, Customer requirement
  • Functional Requirement Software Design - Characteristics of a Good software design
  • Analysis v/s Design
  • classification of cohesion
  • classification of coupling. 2 Function Oriented Software Design – Data flow diagram (DFD)
  • Context level DFD and Level -1 DFD Object-Oriented Modeling with UML – Use case diagram
  • Program Name: Diploma in Engineering Level: Diploma Branch: Computer Engineering / Computer Science & Engineering Subject Code : DI04000011 Subject Name : Software Engineering Class Diagram
  • Component Diagram
  • Sequence Diagram and Activity Diagram

Unit 3 Software Project Estimation & Scheduling

11 lecture hours

  • Responsibility of software project Manager Metrics for Size Estimation - Line of Code
  • Function Points Project Estimation Techniques - COCOMO model Project Scheduling - Gantt Chart
  • Flow Chart
  • Sprint burn down chart for agile model Risk Management - Risk Identification
  • Risk Assessment
  • Risk mitigation and planning
  • Risk Monitoring & Control

Unit 4 Software Coding and Testing

8 lecture hours

  • Coding Coding standards and guidelines
  • Code review - Code Work through and Code Inspection
  • Software Documentation - Internal Documentation and External Documentation
  • Testing Testing Fundamentals
  • Functional Testing – Black box testing
  • Structural Testing – White box testing
  • Overview of Alpha & Beta Testing
  • Overview of Unit testing & Integration testing
  • Test Documentation – test case template
