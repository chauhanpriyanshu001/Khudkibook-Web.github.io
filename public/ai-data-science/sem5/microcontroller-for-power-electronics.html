Microcontroller For Power Electronics Syllabus — Unit-wise Content

The official GTU curriculum for Microcontroller For Power Electronics (subject code 3352404) as prescribed for AI & DS · Semester 5 divides the course into 6 units, covering 16 listed topics. Unit 1 Microcontroll er Basics

  • 1.1. Microcontrollers: need, generalized block diagram, features of microprocessor and microcontroller
  • 1.2. Commercial microcontroller devices.

Unit 2 8051 Architecture

  • 2.1. 8051 microcontroller: Block diagram, Registers; General purpose or working registers, Stack Pointer, Program counter, Special function registers (SFR), Program Status word, Data pointer (DPTR), Timer registers, Ports, Control registers

Unit 3 8051 Connections, I/O Ports and Memory Organization

  • 3.1. 8051 microcontroller: pin description, connections, Parallel I/O ports, RAM organization

Unit 4 8051 Addressing Modes and Instructions

  • 4.1. 8051 microcontroller: assembler and assembling 8051 program, Software simulators.
  • 8051. with suitable examples.
  • 4.2. Addressing modes of 8051
  • 4.3. Instruction set and Examples using various instructions: moving data operation, port programming, arithmetic operations, logical operations, jump and loop operations.

Unit 5 8051 Interrupts, Timer/Counte rs and Serial Communicati on

  • 5.1. Interrupts: Interrupts in 8051, Initializing, priorities.
  • 5.2. Timers and counters: timer counter registers and modes, programming timer interrupts.
  • 5.3. Programming hardware interrupts. Microcontroller for Power Electronics Course code: 3352404 GTU/NITTTR/Bhopal/14-15 Gujarat State 3 Unit Major Learning Outcomes (Major outcomes in cognitive domain) Topics and Sub-topics
  • 5.4. Serial communication: serial communication registers and modes, programming serial communication interrupts.

Unit 6 Microcontroll ers Applications for Power Electronics

  • 6.1. Square wave and rectangular wave generation
  • 6.2. Pulse generation, Pulse width modulation (PWM) generation
  • 6.3. Frequency counter
  • 6.4. Programs based various power electronics applications viz.Interfacing small keyboards, relay, stepper motor, DC motor.
