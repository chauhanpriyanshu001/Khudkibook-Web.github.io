Android App Development Syllabus — Unit-wise Content

The official GTU curriculum for Android App Development (subject code 4361104) as prescribed for EC · Semester 6 divides the course into 5 units, covering 29 listed topics. This curriculum applies from the Jan-2024 intake. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (4361104)

Unit 1 Introduction to MIT App inventor and an App’s Architecture 1.a Use the App Inventor Environment by designing and configuring components i...

  • 1.1. The App Inventor Environment: Component designer, Blocks editor
  • 1.2. App Architecture: Components, Behavior
  • 1.3. An App as a set of event handlers
  • 1.4. Event types: User initiated events, Timer events, Animation events, external events
  • 1.5. Event Handlers response: Repeat block, interact with web, remember things, ask questions

Unit 2 Properties, Variables and Decision making 2.a Change the properties of components in the App Inventor environment. 2.b Defining variables,

  • 2.1. Properties of component
  • 2.2. Defining variables, Setting and getting variables, local and global variables
  • 2.3. Setting variable to an expression, Building complex expressions
  • 2.4. Displaying Variables
  • 2.5. Testing Conditions with if and else if Blocks
  • 2.6. Programming Conditions Within Conditions
  • 2.7. Programming Complex conditions

Unit 3 Creating animated apps and charts 3.a Use the Canvas Components for precise positioning of objects. 3.b Control movement of object on canvas

  • 3.1. Adding a Canvas Component to Your App
  • 3.2. The Canvas Coordinate System
  • 3.3. Animating Objects with Timer Events
  • 3.4. Creating Movement: Speed, collision detection, EdgeReached, CollidingWith, NoLongerCollidingWith
  • 3.5. Plot charts: Line chart, Pie chart, Column chart

Unit 4 Lists, Dictionaries, Procedures and Reusing Blocks 4.a Create and manipulate list

  • 4.1. Creating a List Variable
  • 4.2. Selecting an Item in a List, Using an Index to Traverse a List
  • 4.3. Defining a Dynamic List, Adding an Item, Displaying a List, Removing an Item from a List
  • 4.5. Defining a Procedure, Calling a Procedure
  • 4.6. Adding Parameters to Your Procedure, Returning Values from a Procedure
  • 4.7. Reusing Blocks Among Apps

Unit 5 Communicating with the Sensors and Web 5.a Apply location sensing techniques to create a mobile app that responds to changes in the user'...

  • 8.1. Sensing Location with App Inventor
  • 8.2. Using the Orientation Sensor
  • 8.3. Using the Accelerometer
  • 8.4. Using Bluetooth
  • 8.5. The WebViewer Component
  • 8.6. The Web Component
