Unit 1 Introduction to PLC

  • 1.1. PLC: Characteristics, Operation, function, Types of PLC
  • 1.2. Architecture Of PLC
  • 1.3. Applications of PLC
  • 1.4. PC v/s PLC

Unit 2 Input / Output Modules and Power Supply

  • 2.1. Overview of I/O system.
  • 2.2. Classification: serial, parallel, discrete, analog special
  • 2.3. Direct I/O, Parallel I/O, Serial I/O 2d.Explain Discrete(digital) input and output modules
  • 2.4. discrete input modules: DC input, AC input, Rectifier with filter, Isolation, logic section.
  • 2.5. Discrete output modules: operating principals
  • 2.6. Analog input modules: single ended, differential input
  • 2.7. Common AC source, isolation, protection
  • 2.8. configuration, power line conditioner

  • 3.5. Ladder diagram using timer.
  • 3.6. PLC counter
  • 3.7. Ladder diagram using counter.
