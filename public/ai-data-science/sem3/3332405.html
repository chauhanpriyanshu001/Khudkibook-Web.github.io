Linear Electronic Circuits Syllabus — Unit-wise Content

The official GTU curriculum for Linear Electronic Circuits (subject code 3332405) as prescribed for AI & DS · Semester 3 divides the course into 5 units, covering 14 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (3332405)

Unit 1 Introduction to Operational Amplifiers

  • 1.1. Linear Integrated circuits: classification, packages, pin identification, temperature range and other parameters.
  • 1.2. Amplifier: transistor differential pair, differential amplifier with constant current bias.
  • 1.3. Operational amplifier: definition, block diagram, schematic symbol, current mirror concept

Unit 2 Performance of Op-Amps

  • 2.1. Opamp Parameters: input offset voltage, and current, input bias current, differential input resistance, input capacitance, offset voltage adjustment range, input voltage range, common mode rejection ratio, supply voltage rejection ratio, large signal voltage gain, output voltage swing, output resistance, output short circuit current, supply current, power consumption, transient response, slew rate, gain bandwidth product, average temperature coefficient of input offset voltage and current, noise
  • 2.2. Opamp: Characteristics of ideal op-amp, equivalent circuit, virtual ground.
  • 2.3. Open loop configuration: inverting, non- inverting opamps

Unit 3 Op-Amp with Negative Feedback

  • 3.1. Voltage series feedback: negative feedback, closed loop voltage gain, difference input voltage
  • 3.2. Voltage shunt feedback: closed loop voltage gain, inverting input terminal at virtual ground, current to voltage converter, inverter
  • 3.3. Differential amplifier: with one opamp, two opamps

Unit 4 Linear Applications

  • 4.1. Amplifier: AC, DC, AC amplifier with single supply
  • 4.2. Summing, scaling and averaging amplifier

Unit 5 Comparators and Converters

  • 5.1. Comparator: characteristics, basic comparator, Zero crossing detector, Schmitt trigger and limitations.
  • 5.2. Digital to analog converter: binary weighted, R- 2R
  • 5.3. Analog to digital converter: successive approximation, continuous type.
