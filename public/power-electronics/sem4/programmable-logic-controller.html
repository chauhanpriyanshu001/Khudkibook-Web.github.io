Programmable Logic Controller Syllabus — Unit-wise Content

The official GTU curriculum for Programmable Logic Controller (subject code DI04017031) as prescribed for PE · Semester 4 divides the course into 5 units, covering 71 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (DI04017031)

Unit 1 Introduction of PLCs.

  • 1.1. Introduction of various process control. a) Continuous Process Control. b) Discrete-state Process Control. c) Composite Process Control.
  • 1.2. Introduction of PLC.
  • 1.3. Architecture of PLC.
  • 1.4. Working of PLC.
  • 1.5. Selection Criteria of PLC
  • 1.6. Application of PLC in the Industry.
  • 1.7. Advantages and limitations of PLC.
  • 1.8. Need of Automation in Industries.

Unit 2 Peripherals and Interfacing

  • 2.1. Peripherals devices of plc, Input Devices: Pushbutton, Limit switch, proximity switch, level switch, and other sensing devices. Output Devices: Relay, solid state relay, contactor, solenoid valve, and other controlling devices.
  • 2.2. Ladder logic Symbols of PLC.
  • 2.3. Analog Input/output module.
  • 1. AC input module
  • 2. DC input module
  • 2.4. Digital Input/output module. AC Output module DC Output module
  • 2.5. PLC Input/output interfacing diagram.

Unit 3 Basic of Programming techniques

  • 3.1. Program scan & memory organization. a. PLC operation & program sequence. b. PLC Memory Mapping and I/O addressing for (Allen-Bradley PLC). c. Types of Register use in PLC (Holding, Input, Output register).
  • 3.2. PLC Programming Languages. a. Ladder Logic (LAD) b. Functional Block Diagram (FBD) c. Sequential Functional Chart (SFC) d. Structured Text (ST) e. Instruction List (IL)

  • 3.6. Concept of simple and complex branching in Ladder logic.
  • 3.7. Boolean algebra law using ladder language.

Unit 4 Advance Programming functions

  • 4.1. ON Delay timer, Off Delay timer, Retentive timer, Non-retentive timer
  • 4.2. UP Counter, Down Counter, UP-Down Counter
  • 4.3. PLC arithmetic functions. (Addition, Subtraction, Multiplication, Square Root, Division, Negative
  • 4.4. PLC comparison function (Equal, Not equal, less than, greater than or equal, limit test function)

  • 4.6. Sequencer output (SQO) and Sequencer load (SQL) instruction.
  • 4.7. Data handling instructions: Move, Block Move, Table Move, Register Move.
  • 4.8. Bit Shift Right and Bit Shift Left function.

  • 5.3. LED blinking using various timers.
  • 5.4. DC motor control using PLC.
  • 5.5. Two-way traffic lights system.
  • 5.6. material handling elevator
  • 5.7. Troubleshooting procedure of PLC.
