Artificial Intelligence in Automation Syllabus — Unit-wise Content

The official GTU curriculum for Artificial Intelligence in Automation (subject code DI05000261) as prescribed for PE · Semester 5 divides the course into 5 units, covering 36 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (DI05000261)

Unit 1 Introduction to AI in Industrial Automation

  • 1.1. Overview of AI: Definition and history of AI in manufacturing; Comparison between Conventional Automation vs. AI- based Automation.
  • 1.2. Intelligent Agents: Structure of agents in industrial environments (PLC/SCADA integration); Perception-Action cycle in automated systems.
  • 1.3. AI Search Algorithms: Path planning for AGVs (Automated Guided Vehicles) and AMRs (Autonomous Mobile Robots); Heuristic search basics for optimization.

Unit 2 Machine Learning for Industrial Data

  • 2.1. Data Pre-processing: Handling industrial sensor noise and missing data; Normalization and Feature Extraction from IIoT streams.
  • 2.2. Supervised Learning: Linear and Logistic Regression for sensor calibration; Support Vector Machines (SVM) for equipment state classification.
  • 2.3. Unsupervised Learning: K-means clustering for anomaly detection in process loops; Principal Component Analysis (PCA) for dimensionality reduction.

Unit 3 Neural Networks and Deep Learning

  • 3.1. Artificial Neural Networks (ANN): Biological vs. Artificial Neuron; Multilayer Perceptrons (MLP) and Backpropagation.
  • 3.2. Deep Learning for Automation: Introduction to CNN (Convolutional Neural Networks) for visual inspection; Convolution, Pooling, and Padding layers.
  • 3.3. Time-Series Forecasting:
