Embedded & IoT Systems Syllabus — Unit-wise Content

The official GTU curriculum for Embedded & IoT Systems (subject code DI05000201) as prescribed for EC · Semester 5 divides the course into 3 units, covering 60 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Unit 1 Introduction to Raspberry Pi 1.1 Introduction toRaspberry PiArchitecture

15 lecture hours

  •  Difference between Single Board Computers (SBCs) and microcontroller
  •  Why Raspberry Pi for IoT
  •  Overview of Raspberry Pi models (3B+, 4B, 5)
  •  Hardware specifications (CPU, RAM, USB, HDMI
  • GPIO) 1.2 Hardware Architecture and GPIO Pinout:  Block diagram of Raspberry Pi
  •  40-pin GPIO layout
  •  Digital I/O, PWM, I2C, SPI, UART pins
  •  Safe voltage levels (3.3 V logic)
  •  LED and relay interfacing basics 1.3 Operating System Setup and Linux Basics:  Installing Raspberry Pi OS (Raspbian) using Raspberry Pi Imager
  •  Headless setup (SSH
  •  Essential Linux terminal commands (ls, cd, mkdir
  • nano, apt, sudo
  •  File management andRunning scripts at startup 1.4 Python Programming for Hardware Control:  Python basics — variables
  • data types
  •  RPi.GPIO library for digital I/O
  •  Reading sensors (DHT11 temperature/humidity)
  •  Controlling output devices (LEDs
  •  Thonny IDE usage 1.5 Communication Interfaces and Data Logging:  I2C protocol
  • SPI protocol and UART communication
  •  Logging sensor data to CSV files

Unit 2 Introduction to ESP32 2.1 Introduction to ESP32 Architecture

15 lecture hours

  •  ESP32 vs Arduino UNO vs Raspberry Pi
  •  ESP32 Pinouts and Peripherals
  •  Power consumption and battery-operation suitability Program Name: Diploma Engineering Level: Diploma Branch: Electrical Engineering / Renewable Energy Subject Code: DI05000201 Subject Name: Embedded & IoT Systems 2.2 Development Environment and Programming:  Setting up Arduino IDE for ESP32
  •  Installing ESP32 board package
  •  Uploading and testing code
  •  Introduction to MicroPython on ESP32 using Thonny
  •  Basic programs — digital output, PWM, analog read
  •  Serial Monitor for debugging 2.3 Sensor Interfacing with ESP32:  Interfacing DHT11 / DHT22 (temperature
  •  LDR (light sensor)
  •  Ultrasonic sensor (HC-SR04) for distance
  •  MQ-2 gas/smoke sensor
  •  Pulse sensor for heart rate
  •  GPS module (Neo-6M) for location data
  •  Displaying readings on OLED/LCD 2.4 Wi-Fi Connectivity and IoT Communication Protocols:  Station mode and Access Point mode
  •  Connecting ESP32 to Wi-Fi network
  •  HTTP GET/POST requests to cloud platforms
  •  Sending sensor data to ThingSpeak / Blynk IoT 2.5 ESP32 Web Server:  Creating a local web server on ESP32
  •  Controlling GPIOs via browser
  •  Real-time sensor data display on web page

Unit 3 Embedded IoT Applications 3.1 Home Automation System

15 lecture hours

  •  What is home automation and why it is useful
  •  Block diagram of a simple home automation system (ESP32 as controller
  • relay as switch
  • appliance as load)
  •  Introduction to Blynk IoT app — adding buttons and sliders to control devices from mobile
  •  Practical demonstration of switching two appliances ON/OFF from a mobile app 3.2 Wearable Health Monitoring Device:  What is a wearable device and its use in health monitoring
  •  Sensors used: MAX30102 (heart rate and SpO2) and DHT11 (temperature)
  •  Understanding the output — what is a normal vs. abnormal reading
  • Program Name: Diploma Engineering Level: Diploma Branch: Electrical Engineering / Renewable Energy Subject Code: DI05000201 Subject Name: Embedded & IoT Systems  Simple threshold alert: if heart rate is too high
  • light up a red LED 3.3 GPS-Based Location Tracking System:  What is GPS and how it works (satellites
  • location fix)
  •  GPS module Neo-6M — connecting to ESP32 via UART (Tx, Rx, VCC, GND)
  •  Reading latitude and longitude from Serial Monitor using TinyGPS++ library
  •  Understanding the output data — what latitude and longitude mean
  •  Entering coordinates manually on Google Maps to verify the location
  •  Use cases: school bus tracking
  • vehicle location
  • farm equipment monitoring 3.4 Real-Time Data Collection and Dashboard:  Concept of a data dashboard — seeing live sensor values in one place
  •  Introduction to Node-RED on Raspberry Pi — drag-and-drop visual programming
  •  Adding an MQTT input node and a gauge/chart widget in Node- RED to display sensor data
  •  Setting up a simple alert: when temperature crosses a set value light up Red LED
