Binary

Introduction to Binary System

The binary system is a base-2 number system that uses only two digits, 0 and 1. It is the foundation of digital electronics and computer systems. Binary digits, or bits, are the smallest units of data in digital systems.

Binary Representation

Each binary digit (bit) can represent two states: 0 and 1. For example, the binary number 1011 can be read as 1, 0, 1, 1, where each position represents a power of 2.

Conversion from Binary to Decimal

To convert a binary number to its decimal equivalent, we can use the positional notation method. Each digit in a binary number represents a power of 2, starting from 0 on the right.

Example
Convert the binary number 1011 to its decimal equivalent.

[
1011₂ = 1 × 2³ + 0 × 2² + 1 × 2¹ + 1 × 2⁰ = 8 + 0 + 2 + 1 = 11₁₀
]

Conversion from Decimal to Binary

To convert a decimal number to its binary equivalent, we repeatedly divide the number by 2 and record the remainders.

Example
Convert the decimal number 11 to its binary equivalent.

Reading the remainders from bottom to top, we get 1011₂.

Binary Arithmetic

Binary arithmetic includes addition, subtraction, multiplication, and division. These operations follow similar rules to decimal arithmetic but are simpler due to the limited set of digits (0 and 1).

Binary is used extensively in digital electronics and computer systems for data storage, processing, and transmission. Understanding binary is crucial for designing digital circuits and understanding how computers operate.

Octal

Introduction to Octal System

The octal system is a base-8 number system that uses digits from 0 to 7. It is used as a shorthand for binary numbers, simplifying the representation of large binary numbers.

Octal Representation

Each octal digit represents three bits, making it easier to convert between binary and octal. For example, the octal number 127 can be read as 1, 2, 7, where each position represents a power of 8.

Conversion from Octal to Decimal

To convert an octal number to its decimal equivalent, we can use the positional notation method. Each digit in an octal number represents a power of 8.

Example
Convert the octal number 127 to its decimal equivalent.

[
127₈ = 1 × 8² + 2 × 8¹ + 7 × 8⁰ = 64 + 16 + 7 = 87₁₀

1.2 Number Conversion: Decimal Number system: Decimal to Binary/Hexadecimal/Octal number conversation

Decimal to Binary

To convert a decimal number to binary, we repeatedly divide the number by 2 and record the remainders. The binary number is formed by the remainders read in reverse order.

  • Example:

> Example: Convert the decimal number 25 to binary.

>

> 1. 25 ÷ 2 = 12 remainder 1

> 2. 12 ÷ 2 = 6 remainder 0

> 3. 6 ÷ 2 = 3 remainder 0

> 4. 3 ÷ 2 = 1 remainder 1

> 5. 1 ÷ 2 = 0 remainder 1

>

> Reading the remainders in reverse order: 11001

Thus, the binary equivalent of the decimal number 25 is 11001.

Decimal to Hexadecimal

To convert a decimal number to hexadecimal, we repeatedly divide the number by 16 and record the remainders. The hexadecimal number is formed by the remainders read in reverse order, where 10-15 are represented as A-F.

  • Example:

> Example: Convert the decimal number 123 to hexadecimal.

>

> 1. 123 ÷ 16 = 7 remainder 11 (B)

> 2. 7 ÷ 16 = 0 remainder 7

>

> Reading the remainders in reverse order: 7B

Thus, the hexadecimal equivalent of the decimal number 123 is 7B.

Decimal to Octal

To convert a decimal number to octal, we repeatedly divide the number by 8 and record the remainders. The octal number is formed by the remainders read in reverse order.

  • Example:

> Example: Convert the decimal number 123 to octal.

>

> 1. 123 ÷ 8 = 15 remainder 3

> 2. 15 ÷ 8 = 1 remainder 7

> 3. 1 ÷ 8 = 0 remainder 1

>

> Reading the remainders in reverse order: 173

Thus, the octal equivalent of the decimal number 123 is 173.

Binary Number System: Binary to Decimal/Hexadecimal/Octal Number Conversation

Binary to Decimal

To convert a binary number to decimal, we multiply each digit by 2 raised to the power of its position index (starting from 0 on the right) and sum the results.

  • Example:

> Example: Convert the binary number 11001 to decimal.

>

1. 1 × 2⁴ = 16
2. 1 × 2³ = 8
3. 0 × 2² = 0
4. 0 × 2¹ = 0
5. 1 × 2⁰ = 1

Sum: 16 + 8 + 0 + 0 + 1 = 25

Thus, the decimal equivalent of the binary number 11001 is 25.

Binary to Hexadecimal

To convert a binary number to hexadecimal, we divide the binary number into groups of 4 bits (starting from the right) and convert each group to its hexadecimal equivalent.

  • Example:

> Example: Convert the binary number 11001101 to hexadecimal.

>

> 1. Group the binary number: 1100 1101

> 2. Convert each group: 1100 = C, 1101 = D

>

> Thus, the hexadecimal equivalent of the binary number 11001101 is CD.

Binary to Octal

To convert a binary number to octal, we divide the binary number into groups of 3 bits (starting from the right) and convert each group to its octal equivalent.

  • Example:

> Example: Convert the binary number 11001101 to octal.

>

> 1. Group the binary number: 110 011 01

> 2. Convert each group: 110 = 6, 011 = 3, 010 = 2

>

> Thus, the octal equivalent of the binary number 11001101 is 325.

> 1. Invert each bit: 01010010

> Thus, the 1’s complement of the binary number 10101101 is 01010010.

2’s Complement Binary Addition

Introduction to 2’s Complement

2’s complement is a method used in digital electronics and computing to represent both positive and negative numbers in binary form. This method is particularly useful in arithmetic operations such as addition and subtraction. In 2’s complement, the most significant bit (MSB) is used as a sign bit: 0 for positive numbers and 1 for negative numbers.

Steps to Find 2’s Complement

  1. 1’s Complement: First, find the 1’s complement by inverting all the bits of the binary number.
  2. 2’s Complement: Next, add 1 to the 1’s complement to get the 2’s complement.

Example: Finding 2’s Complement

Example
Find the 2’s complement of the binary number 0101.

1. 1’s Complement: Invert all the bits: 1010.
2. 2’s Complement: Add 1 to the 1’s complement: 1010 + 1 = 1011.

The 2’s complement of 0101 is 1011.

Addition of 2’s Complement Numbers

When adding two 2’s complement numbers, if there is a carry out of the MSB, it is discarded. The result is the 2’s complement of the difference of the two numbers.

Example: 2’s Complement Binary Addition

Example
Perform the 2’s complement addition of 0101 (5) and 1011 (-5).

Step 1: Convert the numbers to their 2’s complement form if they are negative.
- 0101 (5) is already positive.
- 1011 (-5) is in 2’s complement form.

Step 2: Add the numbers.
- 0101
+ 1011
- - - -
- 11000

Step 3: Discard the carry out (1) and consider the result as the 2’s complement of the difference.
- 11000 - 1 = 10111 (11 in decimal, but this is not the final result as the MSB is 1, indicating an overflow).

The result is 10111, which is the 2’s complement of 00000 (0 in decimal).

The result is 10110, which is the 2’s complement of 00010 (2 in decimal).

Subtraction

Introduction to Subtraction

Subtraction in digital systems can be performed using 2’s complement addition. The concept is based on the fact that subtracting a number is equivalent to adding its 2’s complement.

Steps to Perform Subtraction Using 2’s Complement

  1. Find the 2’s Complement: Find the 2’s complement of the number to be subtracted.
  2. Add the Numbers: Add the result to the minuend.
  3. Handle Overflow: If there is a carry out of the MSB, discard it. The result is the 2’s complement of the difference.

Multiplication Binary Codes: Gray Code

Introduction to Gray Code

Gray Code is a non-weighted binary code where only one bit changes between consecutive numbers. This feature makes it useful in applications where errors can occur during transitions, such as in encoders and digital displays.

Gray Code Representation

The Gray code for a binary number can be generated by reflecting the binary number and adding 1 to the result. For example, the Gray code for 0001 is 0001, and the Gray code for 0010 is 0011.

Example: Generating Gray Code

Example
Generate the Gray code for the binary number 0011.

Step 1: Reflect the binary number.
- 0011 reflected is 1100.

Step 2: Add 1 to the reflected number.
- 1100 + 1 = 1101.

The Gray code for 0011 is 1101.

Worked Example: Gray Code

Example
Generate the Gray code for the binary number 0110.

Step 1: Reflect the binary number.
- 0110 reflected is 0110.

Step 2: Add 1 to the reflected number.
- 0110 + 1 = 0111.

The Gray code for 0110 is 0111.

BCD Code

Introduction to BCD Code

BCD (Binary-Coded Decimal) is a form of binary encoding where each decimal digit is represented by a four-bit binary number. BCD is widely used in digital systems, particularly in applications where direct decimal input and output are required, such as in calculators, digital clocks, and some types of computer systems.

BCD Representation:

  • Each decimal digit (0-9) is represented by a 4-bit binary number.
  • For example, the decimal digit 5 is represented as 0101 in BCD.

Types of BCD Codes

  1. 8421 BCD:
  • The most commonly used BCD code.
  • Each decimal digit is represented by a 4-bit binary number where the weights of the bits are 8, 4, 2, and 1.
  • For example, the decimal number 5 is represented as 0101 in 8421 BCD.
  1. 4210 BCD:
  • Each decimal digit is represented by a 4-bit binary number where the weights of the bits are 4, 2, 1, and 0.
  • For example, the decimal number 5 is represented as 0100 in 4210 BCD.
  1. 5421 BCD:
  • Each decimal digit is represented by a 4-bit binary number where the weights of the bits are 5, 4, 2, and 1.
  • For example, the decimal number 5 is represented as 0101 in 5421 BCD.

Example

Example
Convert the decimal number 125 to 8421 BCD.

- The decimal number 125 can be broken down as 125 = 120 + 5.
- 120 is 114 in decimal, which is 10010100 in 8421 BCD.
- 5 is 0101 in 8421 BCD.
- Therefore, the 8421 BCD representation of 125 is 100101000101.

Applications of BCD Code

  • Calculator Displays: BCD is used to display decimal numbers directly without the need for complex conversion algorithms.
  • Digital Clocks: BCD is used to display time in hours, minutes, and seconds.
  • Computer Systems: BCD is used in systems where direct decimal input and output are required.

Code Conversation

Introduction to Code Conversation

Code conversation refers to the process of converting a number from one number system to another. This process is essential in digital systems where data needs to be transmitted, stored, or processed in different formats.

Steps for Code Conversation

  1. Identify the Source and Destination Number Systems:
  • Determine the number system of the source (input) and the number system of the destination (output).
  1. Convert to a Common Intermediate Base:
  • Convert the source number to a common intermediate base, such as binary, before converting it to the destination number system.
  1. Perform the Conversion:
  • Convert the intermediate base number to the destination number system.

Example

Example
Convert the hexadecimal number 3F to binary, then convert the binary number to decimal.

- Step 1: Convert Hexadecimal to Binary
- Hexadecimal 3F can be broken down as 3 and F.
- 3 in binary is 0011.
- F (15 in decimal) in binary is 1111.
- Therefore, the binary representation of 3F is 00111111.

- Step 2: Convert Binary to Decimal
- The binary number 00111111 can be converted to decimal by summing the values of the bits that are set to 1.
- 00111111 = 2⁶ + 2⁵ + 2⁴ + 2³ + 2² + 2¹ + 2⁰ = 64 + 32 + 16 + 8 + 4 + 2 + 1 = 127.
- Therefore, the decimal representation of 3F is 127.

Applications of Code Conversation

  • Data Transmission: Code conversation is used in digital communication systems to ensure data is transmitted in the correct format.
  • Data Storage: Code conversation is used in memory systems to store data in various formats.
  • Data Processing: Code conversation is used in digital systems to process data in different formats.

Hexadecimal Number System: Hexadecimal to Decimal/Binary/Octal Number Conversation

Introduction to Hexadecimal Number System

The hexadecimal number system is a base-16 number system. It uses 16 distinct symbols, 0-9 and A-F, where A-F represent the decimal values 10-15.

Conversion from Hexadecimal to Decimal

  1. Identify the Position of Each Digit:
  • Each position in a hexadecimal number has a power of 16.
  • The rightmost digit has a position of 16⁰, the next digit to the left has a position of 16¹, and so on.
  1. Multiply Each Digit by Its Position Value:
  • Multiply each digit by its position value and sum the results.

Example

Example
Convert the hexadecimal number A2 to decimal.

- The position values are: 2 (16⁰) and A (16¹).
- A in decimal is 10.

Introduction to Octal Number System

The octal number system is a base-8 numeral system that uses the digits 0 to 7. It is often used in digital systems as a shorthand for binary numbers, since each octal digit corresponds to exactly three binary digits (bits).

Conversion from Octal to Decimal

To convert an octal number to its decimal equivalent, each digit in the octal number is multiplied by 8 raised to the power of its position, starting from 0 on the right.

Example

Convert the octal number 752 to its decimal equivalent.

To convert an octal number to binary, each octal digit is replaced by its 3-bit binary equivalent.

To convert an octal number to hexadecimal, first convert the octal number to binary, and then group the binary digits into sets of four, starting from the right. If necessary, pad with zeros to make complete groups. Each group of four binary digits is then converted to its hexadecimal equivalent.
