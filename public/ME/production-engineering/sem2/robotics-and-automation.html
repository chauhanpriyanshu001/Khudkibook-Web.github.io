Robotics and Automation Syllabus — Unit-wise Content

The official GTU curriculum for Robotics and Automation (subject code ME02000871) as prescribed for PE · Semester 2 divides the course into 8 units, covering 87 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (ME02000871)

Unit 1 Introduction to Robotics

20 lecture hours

  • 08 Program Name: Master of Engineering Level: PG Subject Code: ME02000871 Subject Name : Robotics and Automation Brief history
  • robot technology
  • Basic Terminologies
  • classification, and characteristics
  • physical configuration
  • structure of industrial robot
  • Robot Drives
  • Actuators and Controls: Drives: Functions of Drive system
  • General types of fluids
  • Hydraulic and Pneumatic systems
  • Electrical drives
  • DC motors and transfer functions
  • AC motors
  • piezoelectric Actuators
  • Stepper motors
  • Drive Mechanisms
  • Grippers: Types of Grippers
  • Design aspect for gripper
  • Force analysis for various basic gripper systems including Mechanical
  • Robot Sensors: Robot Transducers and Sensors
  • Tactile sensor
  • Proximity and range sensors
  • Sensing joint forces
  • Robotic vision system
  • Image grabbing
  • Image processing and analysis
  • Image segmentation, etc
  • Design and control of sensor Integrated Dexterous robot hand

Unit 2 Kinematics and Dynamics of Robotics

6 lecture hours

  • Transformation matrices and their arithmetic
  • link and joint description
  • Denavit Hartenberg parameters
  • frame assignment to links
  • direct kinematics
  • Dynamics: Introduction to Dynamics
  • Trajectory generations
  • Manipulator Mechanism Design

Unit 3 Robot Cell Design

6 lecture hours

  • Robot work cell design and control
  • Safety in Robotics
  • Robot cell layouts
  • Multiple Robots and machine interference
  • Robots cycle time analysis
  • Industrial application of robots

Unit 4 Robot Programming

6 lecture hours

  • Lead through programming
  • Robot programming as a path in space
  • Motion interpolation
  • SINGNAL AND DELAY commands
  • Branching capabilities and Limitations
  • Robot languages: Textual robot languages
  • Robot language structures
  • Elements in function

Unit 5 Robotics application and advances

6 lecture hours

  • Material transfer
  • Machine loading/unloading
  • Processing operation
  • Assembly and Inspection
  • Feature Application
  • Economical aspects for robot design
  • Safety for robot and associated mass
  • New Trends and recent updates in robotics
  • International Scenario for implementing robots in Industrial and other sectors
  • Future scope for robotization

Unit 6 Automation

8 lecture hours

  • 03 Program Name: Master of Engineering Level: PG Subject Code: ME02000871 Subject Name : Robotics and Automation Definition
  • Benefits of Automation
  • Types of automation
  • Typical Features and examples
  • Reasons for automating
  • Automation strategies
  • Automated flow lines
  • General forms of Workflow
  • Criteria for selection
  • Methods of work part transport
  • Transfer Mechanisms

Unit 7 Hardware Components and Process Control

6 lecture hours

  • Analogue to digital convertors
  • Digital to Analogue convertors
  • Input/Output devices for discrete data
  • Control system: Continuous and Discrete control
  • Computer process control: Logic control
  • Ladder logic diagrams
  • Programmable Logical control
  • Application of computer technology
  • Automatic identification and data capture: Bar code technology
  • AIDC technology

Unit 8 Automated Production Line

4 lecture hours

  • System configuration
  • Work part transfer mechanism
  • Storage buffer and control
  • Application, and analysis of transfer lines
  • Automated Assembly Systems: Assembly System Configuration
  • Quantitative analysis of Assembly systems
