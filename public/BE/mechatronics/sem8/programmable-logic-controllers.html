Programmable Logic Controllers Syllabus — Unit-wise Content

The official GTU curriculum for Programmable Logic Controllers (subject code 2182001) as prescribed for Mechatronics · Semester 8 divides the course into 4 units, covering 19 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (2182001)

Unit 1 PLC Basics

3 lecture hours

  • Introduction to Programmable Logic Controllers (PLCs)
  • history of PLCs
  • Advantages of PLCs and Comparison of PLC based control systems with other conventional control systems

Unit 2 PLC Hardware

4 lecture hours

  • Block diagram of PLC, Internal architecture of PLC, Digital and Analog Input output modules of PLCs
  • scan cycle and scan time
  • connections and wiring of various Inputs and Outputs of Plants with the PLC

Unit 3 Basics of PLC programming

10 lecture hours

  • Overview of various programming languages of PLCs: (1) Ladder diagram
  • (2) Functional Block Diagram (FBD)
  • (3) Instruction List (IL)
  • (4) Sequential Flow Chart (SFC) Programming of On-Off inputs and outputs
  • producing boolean equation from given PLC program
  • design of PLC program from given boolean function using above programming languages

Unit 4 PLC Timers and Counter Instructions

10 lecture hours

  • Various types of PLC timers with detailed timing diagrams: On delay timer
  • Off delay timer
  • Retentive on delay timer
  • Pulse timer
  • Various types of PLC counters: Up counter
  • Down counter
  • Up-Down counter Programming of various applications using timers and counters using Ladder diagram only
