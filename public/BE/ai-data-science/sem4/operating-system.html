Operating System Syllabus — Unit-wise Content

The official GTU curriculum for Operating System (subject code BE04000221) as prescribed for AI & DS · Semester 4 divides the course into 9 units, covering 69 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (BE04000221)

Unit 1 Introduction

4 lecture hours

  • Computer system overview
  • Goals & Structures of O.S
  • Basic functions
  • Interaction of O.S. & hardware architecture
  • System calls
  • time sharing
  • distributed & real-time O.S

Unit 2 Process and Threads Management

5 lecture hours

  • Process Concept
  • Process states
  • Process control
  • Uni-processor Scheduling: Types of scheduling: Preemptive
  • Non preemptive
  • Scheduling algorithms: FCFS, SJF, RR, Priority
  • Thread Scheduling
  • Real Time Scheduling
  • System calls like ps, fork
  • exec family

Unit 3 Concurrency & Synchronization

5 lecture hours

  • Principles of Concurrency
  • Mutual Exclusion: S/W approaches
  • Message Passing
  • Signals, and Monitors

Unit 4 Inter Process Communication

6 lecture hours

  • Race Conditions
  • Critical Section
  • Mutual Exclusion
  • Hardware Solution
  • Strict Alternation
  • Peterson’s Solution
  • The Producer Consumer Problem
  • Event Counters
  • Message Passing
  • Classical IPC Problems: Reader’s & Writer Problem
  • Dining Philosopher Problem etc.
  • Scheduling concept and Scheduling Algorithms

Unit 5 Deadlock

3 lecture hours

  • Principles of Deadlock
  • Deadlock Prevention
  • Deadlock Avoidance
  • Deadlock Detection
  • System calls

Unit 6 Memory Management

7 lecture hours

  • Memory Management requirements
  • Memory partitioning: Fixed and Variable Partitioning
  • Memory Allocation: Allocation Strategies (First Fit, Best Fit, and Worst Fit)
  • Paging and Fragmentation
  • Demand Paging
  • Security Issues
  • Virtual Memory: Concepts
  • VM management
  • Page Replacement Policies (FIFO, LRU, Optimal
  • Other Strategies)

Unit 7 I/O Management & Disk scheduling

5 lecture hours

  • Organization of I/O functions
  • Operating System Design issues
  • Disk Scheduling (FCFS
  • Disk Cache

Unit 8 Unix/Linux Operating System

  • Development Of Unix/Linux
  • Role & Function Of Kernel
  • System Calls
  • Elementary Linux command & Shell Programming
  • Directory Structure
  • System Administration 05 Program Name: Bachelor of Engineering Level: UG Subject Code: BE04000221 Subject Name: Operating Systems Case study: Linux
  • Windows Operating System

Unit 9 Virtualization Concepts

5 lecture hours

  • Virtual machines
  • supporting multiple operating systems simultaneously on a single hardware platform
  • running one operating system on top of another
  • True or pure virtualization
  • Approaches to Virtualization: Processor Issue
  • Memory Management
  • VMware ESXi
  • Microsoft Hyper-V and Xen Variants
  • Java VM, Linux VServer Virtual MachineArchitecture
  • Android Virtual Machine
