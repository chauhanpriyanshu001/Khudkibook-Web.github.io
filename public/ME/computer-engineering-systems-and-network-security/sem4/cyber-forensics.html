Cyber Forensics Syllabus — Unit-wise Content

The official GTU curriculum for Cyber Forensics (subject code 2745603) as prescribed for CE(A · Semester 4 divides the course into 4 units, covering 25 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (2745603)

Unit 1 Introduction to Cyber Forensics

6 lecture hours

  • Definition of Cyber forensics? Its importance in Cyberspace
  • Relation between Cyber Crime-Cyber Forensics and Cyber Security
  • Classification of Cyber Forensics
  • Goals of Cyber Forensics
  • Forensic Investigation process
  • Benefits of professional forensic methodology
  • Case Study: Investigation of any Attack like phishing or stalking

Unit 2 Pre-Investigation Assessment

4 lecture hours

  • Preliminary Review of the Scene of offence: Evaluation
  • Preliminary Interviews
  • Incident Response
  • Incident Response Team
  • Pre- Investigation Technical Assessment

Unit 3 Standard Operating Procedures for Investigation

6 lecture hours

  • Steps for digital crime scene investigation
  • Evidence Collection Procedures from live systems and Switched-off Systems
  • Types and Rules of Evidence
  • Forensic Duplication
  • Documenting of Evidence
  • Chain of Custody

Unit 4 Investigation Tools and Utilities

10 lecture hours

  • Drive Imaging
  • Memory Dump creation and analysis
  • Data Recovery Tools, and Introduction to Deleted-Hidden-Encrypted file Recovery
  • Formatted Partition Recovery
  • Time line analysis of file modification and file access
  • Recover Temporary Files or Cache Files
  • Open Source Forensic Tools
