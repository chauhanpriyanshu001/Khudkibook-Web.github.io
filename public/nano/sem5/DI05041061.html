Network System and Communications Syllabus — Unit-wise Content

The official GTU curriculum for Network System and Communications (subject code DI05041061) as prescribed for Nano · Semester 5 divides the course into 4 units, covering 36 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (DI05041061)

Unit 1 Fundamentals of Networking System & Communication

  • 1.1. Need, Advantages and Applications of Computer Networks
  • 1.2. Physical topologies of Network : Star, Ring, Bus, Mesh, Tree, Hybrid
  • 1.3. Internet Standards: Protocol, Interface, Services, Primitives, semantics, syntax
  • 1.4. Network Classification i. Based on Transmission Technologies: Point-to point, broadcast ii. Based on scale: LAN, WAN, MAN,VPN, Internet iii. Based on Architecture: Peer to Peer, Client Server, advantages of Client Server over Peer- to-Peer Model
  • 1.5. OSI and TCP/IP models and their comparison
  • 1.6. Concepts in Data Communication Networking.

Unit 2 Networking Devices

  • 2.1. Classification of Transmission Media: Role of different devices
  • 2.2. Repeaters, Hubs, Bridges, Switches(layer 2 and layer 3)
  • 2.4. Access Points
  • 2.6. Introduction to Network management system (OS, CLI, Administrative Functions, Interfaces)
  • 2.7. Ethernet, Fast Ethernet, Gigabit Ethernet
  • 2.8. Wireless LAN

Unit 3 Networking System Hardware

  • 3.1. Physical Layer: Transmission media (Twisted pair, Coaxial cable, Fiber optic cable)
  • 3.2. Physical Layer Interfaces: Types of Connectors
