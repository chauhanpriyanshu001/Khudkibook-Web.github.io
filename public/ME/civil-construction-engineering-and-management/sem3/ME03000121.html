Operational Research Syllabus — Unit-wise Content

The official GTU curriculum for Operational Research (subject code ME03000121) as prescribed for C(EA · Semester 3 divides the course into 7 units, covering 49 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (ME03000121)

Unit 1 Basics of Optimization

2 lecture hours

  • General methods for operation research models
  • introduction to linear and non-linear programming formulation of different models

Unit 2 Linear Programming Problems

10 lecture hours

  • Properties of Linear Programming Solution
  • Formulation of a LPP, - graphical solution
  • simplex method
  • Big M Method
  • Dual Simplex method
  • duality in LPP, sensitivity analysis
  • Integer linear programming
  • revised simplex method
  • parametric linear programming
  • Dynamic programming under certainty
  • Dynamic programming approach for solving LPP

Unit 3 Project Management and Inventory Control

6 lecture hours

  • CPM, PERT
  • Crashing of Project Network
  • Project Scheduling with Constrained Resources
  • Models of Inventory
  • Operation of Inventory system
  • Purchase Inventory model
  • Multiple-item Model with Shortage limitation
  • EOQ Model for Purchase Model for Multi-item Joint Replenishment

Unit 4 Decision and Game Theory

7 lecture hours

  • Decision under Certainty
  • Decision under Risk
  • Decision under Uncertainty
  • Decision Tree
  • Theory of games
  • Game with Pure Strategies
  • Game with Mixed Strategies
  • Saddle point
  • Dominance Property

Unit 5 Classical Optimization Methods

7 lecture hours

  • Single variable optimization
  • Program Name: Master of Engineering Level: PG Subject Code: ME03000121 Course/Subject Name: Operational Research Constrained and unconstrained multi-variable optimization
  • Direct substitution method
  • Lagrange’s method of multipliers
  • Kuhn Tucker conditions

Unit 6 Non-linear Programming

10 lecture hours

  • Constrained Optimization Techniques Unimodal function
  • Unrestricted search
  • Exhaustive search
  • Dichotomous search
  • Interval halving method
  • Fibonacci method
  • Golden section method Unconstrained Optimization Techniques Direct Search Methods: Random search methods
  • Grid search method
  • Univariate method
  • Constrained Optimization Techniques Direct Methods: Random search method
  • Sequential linear programming

Unit 7 Evolutionary Algorithms An overview of evolutionary algorithms,

3 lecture hours

  • Simulated annealing algorithm
  • Genetic algorithm
  • Particle swarm optimization
