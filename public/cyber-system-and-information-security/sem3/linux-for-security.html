Linux for Security Syllabus — Unit-wise Content

The official GTU curriculum for Linux for Security (subject code DI03066011) as prescribed for CSAI · Semester 3 divides the course into 6 units, covering 64 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (DI03066011)

Unit 1 Introduction to Kali Linux and Cybersecurity Lab

6 lecture hours

  • Environment Introduction to Kali Linux: purpose
  • history, and comparison with Ubuntu and Parrot OS Kali Linux variants: Full Install
  • Live Boot
  • Kali NetHunter (mobile)
  • Kali on WSL Lab environment setup: installing Kali Linux and Ubuntu on VirtualBox/VMware
  • configuring NAT, Bridged, and Host- only network modes
  • Managing Kali packages- apt update
  • apt upgrade
  • apt install
  • verifying tool integrity using checksums and GPG signatures

Unit 2 File System Management and Navigation

8 lecture hours

  • File and Directory Management: mkdir
  • nano, cat, less
  • renaming and deleting files and directories Linux File System Hierarchy and Navigation: /etc
  • Hard links and symbolic links- ln, ln -s
  • Searching files- find
  • whereis Text processing for security: grep, awk, sed, cut, sort
  • uniq Program Name: Diploma Engineering Level: Diploma Branch: Cyber System and Information Security Subject Code: DI03066011 Subject Name: Linux for Security

Unit 3 User, Group Management and File Permissions

10 lecture hours

  • User and Group Management: adduser
  • Group Management- groupadd
  • gpasswd, id, groups
  • /etc/group file structure and security implications File Permissions and Ownership: chmod (symbolic & numeric)
  • Default permissions and umask configuration
  • Special permission bits- SUID
  • Access Control Lists (ACLs)- setfacl
  • getfacl for granular access control
  • Sudo configuration: /etc/sudoers
  • principle of least privilege

Unit 4 Process Management and Package Management

8 lecture hours

  • Process Management: ps, top, htop
  • jobs, bg, fg, nohup
  • understanding process hierarchy and zombie/orphan processes
  • Security perspective- identifying malicious processes and suspicious PIDs Package Management on Debian/Ubuntu: apt, dpkg
  • Verifying package integrity- checksums
  • GPG signatures

Unit 5 Networking, Network Commands and Essential Security

14 lecture hours

  • Tools Networking Basics: IP addressing, DNS, Gateway
  • subnetting fundamentals
  • nslookup, dig, host
  • netstat, ss, lsof -i – identifying open ports
  • ip addr
  • ip route
  • ip link Network Reconnaissance and Packet Analysis Tools: SYN scan
  • UDP scan
  • OS & service detection
  • whois – gathering target information
  • tcpdump – filters
  • saving and reading pcap files
  • Netcat (nc)- banner grabbing
  • port testing
  • simple file transfer Program Name: Diploma Engineering Level: Diploma Branch: Cyber System and Information Security Subject Code: DI03066011 Subject Name: Linux for Security

Unit 6 Linux Security Automation, Log Monitoring, and System

14 lecture hours

  • Hardening Bash Scripting Fundamentals: variables
  • data types
  • Control structures: if-else
  • while, for, until loops
  • exit codes and error handling in scripts Automation with Bash: writing practical security automation scripts
  • Crontab jobs: crontab -e
  • cron.daily System Logs and Monitoring: /var/log/syslog
  • lastb, who, w, Parsing logs with grep, awk, and sed Linux System Hardening: UFW – rules
  • Fail2Ban: configuration
  • banning IPs, monitoring logs
  • SELinux: modes (enforcing
  • AppArmor: profiles
  • aa- complain
  • SSH hardening: key-based auth
  • disabling root login
  • port change
