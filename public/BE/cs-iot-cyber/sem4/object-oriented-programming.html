Object Oriented Programming Syllabus — Unit-wise Content

The official GTU curriculum for Object Oriented Programming (subject code BE04000231) as prescribed for CS-IoT · Semester 4 divides the course into 8 units, covering 67 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (BE04000231)

Unit 1 Basic of Java

3 lecture hours

  • Java Platform and Architecture (JVM, JDK, JRE)
  • Java Program Structure
  • Compilation, and Execution Java program
  • Data types (byte
  • short, int, long
  • operator precedence and associativity
  • type conversion

Unit 2 Conditional and looping statements

3 lecture hours

  • simple if, if-else statement
  • else-if ladder
  • switch-case statement
  • for loop
  • while loop
  • do-while loop
  • Enhanced for Loop (for-each loop)
  • labelled break
  • labelled continue

Unit 3 Basics of Object Oriented Programming

7 lecture hours

  • Data Encapsulation by defining classes
  • data members
  • member functions
  • Data Abstraction
  • access specifiers
  • static data member and static member function
  • defining constructors
  • objects and references
  • this keyword
  • returning and passing objects
  • array of objects
  • static block
  • instance block
  • inner class

Unit 4 Inheritance, Polymorphism and Wrapper classes

8 lecture hours

  • types of inheritance
  • this and final keywords
  • method overloading
  • method overriding
  • dynamic binding
  • casting objects
  • instanceof operator
  • protected data members
  • StringBuffer and StringBuilder class
  • Wrapper classes for Primitive types
  • Collection framework
  • Java API Packages
  • User-defined packages

Unit 5 Interface, Abstract class and Exception Handling

7 lecture hours

  • Partial interface
  • Multiple inheritance using interface
  • Abstract class
  • Abstract methods
  • Handling Exception using try, catch and finally keywords
  • Throwing exception using throw
  • checked and unchecked exception
  • throws keyword
  • Creating user-defined exceptions

Unit 6 Concurrency control

5 lecture hours

  • Thread life cycle
  • Creating threads using Thread class and runnable interface
  • Thread methods
  • Thread synchronization using synchronized keyword

Unit 7 I/O Management and Generics

6 lecture hours

  • File class
  • reading and Random Access files
  • Purpose of Generics
  • Defining Generic classes and methods
  • Generics with Collections like ArrayList
  • HashMap, etc

Unit 8 Designing GUI Applications using JavaFx

45 lecture hours

  • Basic structure of JavaFx application
  • Layout Panes
  • UI Components
  • Color and Font classes
  • Event Handling 6 10 Program Name: Bachelor of Engineering Level: UG Subject Code: BE04000231 Subject Name: Object Oriented Programming
