Software Engineering Syllabus — Unit-wise Content

The official GTU curriculum for Software Engineering (subject code 3150711) as prescribed for CSE · Semester 5 divides the course into 10 units, covering 77 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (3150711)

Unit 1 Introduction to Software and Software Engineering

5 lecture hours

  • The Evolving Role of Software
  • Software: A Crisis on the Horizon and Software Myths
  • Software Engineering: A Layered Technology
  • Software Process Models
  • The Linear Sequential Model
  • The Prototyping Model
  • The RAD Model
  • Evolutionary Process Models
  • Agile Process Model
  • Component-Based Development
  • Product and Process

Unit 2 Agile Development

3 lecture hours

  • Agility and Agile Process model
  • Extreme Programming
  • Other process models of Agile Development and Tools
  • Subject Code: 3150711 w.e.f

Unit 3 Managing Software Project

4 lecture hours

  • Software Metrics (Process
  • Product and Project Metrics)
  • Software Project Estimations
  • Software Project Planning (MS Project Tool)
  • Project Scheduling & Tracking
  • Risk Analysis &Management (Risk Identification
  • Risk Projection
  • Risk Refinement
  • Risk Mitigation)

Unit 4 Requirement Analysis and Specification

3 lecture hours

  • Understanding the Requirement
  • Requirement Modeling
  • Requirement Specification (SRS)
  • Requirement Analysis and Requirement Elicitation
  • Requirement Engineering

Unit 5 Software Design

4 lecture hours

  • Design Concepts and Design Principal
  • Architectural Design
  • Component Level Design (Function Oriented Design
  • Object Oriented Design)
  • User Interface Design
  • Web Application Design

Unit 6 Software Coding & Testing

5 lecture hours

  • Coding Standard and coding Guidelines
  • Code Review
  • Software Documentation
  • Testing Strategies
  • Testing Techniques and Test Case
  • Test Suites Design
  • Testing Conventional Applications
  • Testing Object Oriented Applications
  • Testing Web and Mobile Applications
  • Testing Tools (Win runner
  • Load runner)

Unit 7 Quality Assurance and Management

3 lecture hours

  • Quality Concepts and Software Quality Assurance
  • Software Reviews (Formal Technical Reviews)
  • Software Reliability
  • The Quality Standards: ISO 9000, CMM, Six Sigma for SE, SQA Plan

Unit 8 Software Maintenance and Configuration Management

3 lecture hours

  • Types of Software Maintenance
  • Reverse Engineering
  • Forward Engineering
  • The SCM Process
  • Identification of Objects in the Software Configuration
  • Version Control and Change Control

Unit 9 DevOps

4 lecture hours

  • Problem Case Definition
  • Benefits of Fixing Application Development Challenges
  • DevOps Adoption Approach through Assessment
  • Solution Dimensions
  • What is DevOps?
  • DevOps Importance and Benefits
  • DevOps Principles and Practices
  • 7 C’s of DevOps Lifecycle for Business Agility
  • DevOps and Continuous Testing
  • How to Choose Right DevOps Tools
  • Challenges with DevOps Implementation
  • Must Do Things for DevOps
  • Mapping My App to DevOps - Subject Code: 3150711 w.e.f
  • AY 2018-19 Assessment
  • Measure and Feedback

Unit 10 Advanced Topics in Software Engineering

2 lecture hours

  • Component-Based Software Engineering
  • Client/Server Software Engineering
  • Web Engineering
  • Computer-Aided Software Engineering
  • Software Process Improvement
  • Emerging Trends in software Engineering
