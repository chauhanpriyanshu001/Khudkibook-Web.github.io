Process Instrumentation, Dynamics & Control Syllabus — Unit-wise Content

The official GTU curriculum for Process Instrumentation, Dynamics & Control (subject code 2183607) as prescribed for Chem. Tech. · Semester 8 divides the course into 4 units, covering 29 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (2183607)

Unit 1 Introduction of Process Control

3 lecture hours

  • Introduction to Industrial Process Control
  • Strategies for Control Feedback/ Feed forward Steady state system
  • Process control
  • Feedback control
  • Transient response
  • Block diagram
  • Parts of control system

Unit 2 Laplace Transforms

3 lecture hours

  • Transforms of simple functions
  • Ramp functions
  • Sine functions
  • Inversions of transform function by partial fractions
  • Final value and initial value theorems
  • Translation of transforms
  • Transforms of unit impulse functions
  • Transforms of integral

Unit 3 First Order Systems

7 lecture hours

  • Mercury thermometer
  • Transient response of step functions
  • Sinusoidal input
  • Impulse functions
  • Physical Examples of First Order Systems such as Liquid level
  • Mixing process
  • Response of First Order System in Series: Non-interacting system of liquid level
  • Generalization of several non- interacting systems in series
  • Interacting systems

Unit 4 Second Order Systems

7 lecture hours

  • Development of transfer functions
  • Liquid manometer
  • Step response & impulse response
  • Terms used to describe second order system
  • Transportation lag
