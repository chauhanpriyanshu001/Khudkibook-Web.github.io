Embedded Systems for Robotics Syllabus — Unit-wise Content

The official GTU curriculum for Embedded Systems for Robotics (subject code DI04041011) as prescribed for Nano · Semester 4 divides the course into 5 units, covering 38 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (DI04041011)

Unit 1 Introduction to Embedded System

  • 1.1. Embedded System definition, block diagram.
  • 1.2. Embedded system architectures: Von Neumann vs Harvard.
  • 1.3. Classification and characteristics of embedded systems.
  • 1.4. Applications of embedded system.
  • 1.5. Criteria for choosing microcontroller
  • 1.6. Derivatives of microcontroller (from manufacturers Intel, Atmel, Microchip, Arduino).

Unit 2 AVR Microcontroller Architecture

  • 2.1. History of the AVR microcontroller.
  • 2.2. Features of AVR microcontroller
  • 2.3. AVR family overview
  • 2.4. Architecture of AVR microcontroller (ATmega32)
  • 2.5. Data memory: General Purpose Registers, I/O Memory, Internal data SRAM, EEPROM Memory
  • 2.6. Status register
  • 2.7. Program Counter and memory
  • 2.8. ATmega32 pin diagram
  • 2.9. Input/ output ports pins, circuits & their alternate functions.
  • 2.10. AVR fuse bits.
  • 2.11. Clock and Reset Circuits
  • 2.12. Operation of Timer/Counter in various mode.

Unit 3 AVR Programming in C

  • 3.1. Data types and time delays in C.
  • 3.2. I/O programming in C. (Byte size and bit size I/O)
  • 3.3. Logic operations in C. (Bit-wise logic operators e.g. AND, OR, EX-OR, Inverter and shift operation.
  • 3.4. Data serialization in C.
  • 3.5. Memory allocation and programming in C.
  • 3.6. Programming timers in C.
  • 3.7. Interrupt programming in C.
  • 3.8. AVR serial port programming in C.

Unit 4 AVR Interfacing

  • 4.1. LCD and Keyboard interfacing
  • 4.2. ADC, DAC and sensor (LM 35) interfacing.
  • 4.3. Relay, Opto-isolator and stepper-motor

  • 4.4. Interfacing of MAX7221
  • 4.5. Basic c programs for above interfacing devices using Atmega32.

Unit 5 Embedded Robotic Applications

  • 5.1. Speed DC motor control and PWM
  • 5.2. Line follower robot
  • 5.3. Obstacle avoidance robot
  • 5.4. Robotic arm control
