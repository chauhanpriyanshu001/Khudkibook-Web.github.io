Web Programming Syllabus — Unit-wise Content

The official GTU curriculum for Web Programming (subject code 3160713) as prescribed for CS-Design · Semester 6 divides the course into 4 units, covering 61 listed topics. Unit 1 Introduction to WEB

4 lecture hours

  • Basics of WWW, HTTP protocol
  • Client Server architecture
  • Introduction to web server installation and configuration 04 7% Web Design Concepts of effective web design
  • Web design issues including Browser
  • Bandwidth and Cache
  • Display resolution
  • Look and Feel of the Website
  • Page Layout and linking
  • User centric design
  • Planning and publishing website
  • Designing effective navigation

8 lecture hours

  • Structure of HTML page
  • HTML tags for data formatting
  • meta tags
  • html form tags
  • HTML5 tags and validation
  • Need for CSS, Syntax and structure
  • CSS rules for Backgrounds
  • Colors and properties
  • Manipulating texts
  • borders and boxes
  • Padding Lists
  • CSS Positioning
  • Style images
  • Media Queries
  • Wildcard Selectors (*
  • ^ and $) in CSS, Working with Gradients
  • Pseudo Class
  • Pseudo elements
  • basic of frameworks like Bootstrap

Unit 3 Client Side Scripting using JavaScript

10 lecture hours

  • Syntax of JavaScript
  • Execution of JavaScript
  • Embedded and External Javascript
  • JavaScript : variables
  • Pop up boxes
  • JavaScript objects and DOM, JavaScript inbuilt functions
  • JavaScript validations and Regular expressions
  • Event handling with JavaScript
  • Callbacks in Javascript
  • Function as arguments in JavaScript
  • Introduction to JSON Subject Code: 3160713 w.e.f

8 lecture hours

  • Form processing
  • File uploads
  • Dates and time zone

  • State management using query string
  • hidden form controls
