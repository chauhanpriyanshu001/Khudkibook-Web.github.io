Networking System and Communication Syllabus — Unit-wise Content

The official GTU curriculum for Networking System and Communication (subject code DI05020041) as prescribed for Production · Semester 5 divides the course into 5 units, covering 23 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Download the official syllabus PDF (DI05020041)

Unit 1 Fundamentals of Networking System & Communication

8 lecture hours

  • Advantages and Applications of Computer Networks 1.2 Physical topologies of Network 1.3 Internet Standards: Protocol
  • syntax 1.4 Network Classification (i) Based on Transmission Technologies: Point-to point
  • broadcast (ii) Based on scale: PAN, LAN, WAN, MAN, VPN, Internet (iii) Based on Architecture: Peer to Peer
  • Client Server
  • advantages of Client Server over Peer- to-Peer Model 1.5 Layering of Models 1.6 OSI and TCP/IP models and their comparison 1.7 Concept of Internet model. 1.8 Concepts in Data Communication Networking

Unit 2 Networking Devices

8 lecture hours

  • 2.1 Classification of Transmission Media: Role of different devices 2.2 Repeaters
  • Switches(layer 2 and layer 3) 2.3 Routers 2.4 Access Points 2.5 Introduction to Network management system (OS, CLI, administrative Functions
  • Interfaces) 2.6 Ethernet
  • Fast Ethernet
  • Gigabit Ethernet 2.7 Wireless LAN

Unit 3 Networking System Hardware Layers

13 lecture hours

  • 3.1 Physical Layer: Transmission media 3.2 Physical Layer Interfaces: Types of Connectors and Signals 3.3 Circuit switching 3.4 Cable modem 3.5 Sub Layers of Data Link Layer and functions: Error control
  • Flow control examples 3.6 Data link protocol HDLC, PPP, Multiple Access
  • CSMA/CA. 3.9 Network Layer: Packet Switching
  • 3.10 Virtual circuits, and datagram
  • Static and Dynamic Routing Algorithms 3.11 Types of IP Addressing 3.12 IP layer protocols 3.13 IPv4 and IPv6 comparison 3.14 Line coding types Program Name: Diploma Engineering Level: Diploma Branch: Mechatronics Engineering / Subject Code: DI05020041 Subject Name: Networking System and Communication w.e.f. 2025-26 http://syllabus.gtu.ac.in/ Page | 4

Unit 4 Networking System Software Layers

8 lecture hours

  • 4.1 Transport Layer: Elements of Transport protocols - TCP & UDP, Connection oriented and connection less network. 4.2 Application Layer: DNS- Domain Name System
  • Internet Services
  • Electronic Mail 4.3 Voice and Video over IP 4.4 Social services: Forum

Unit 5 Network Security

8 lecture hours

  • 5.1 Introduction to Network Security
  • symmetric and asymmetric encryption algorithms 5.2 IP security: SSH and Web security 5.3 Information Security Standards - ISO, IT Act, Copyright Act, Cyber Laws in India. 5.4 IT Act 2000 Provisions and late statements 5.5 Social issues
  • precautions 5.6 Firewalls: Working and Design Principle
  • Packet Filter Firewall
  • Proxy Firewall
