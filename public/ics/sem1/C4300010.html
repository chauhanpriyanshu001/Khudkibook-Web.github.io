Basics of Information and Communication Technology Syllabus — Unit-wise Content

The official GTU curriculum for Basics of Information and Communication Technology (subject code C4300010) as prescribed for ICT · Semester 1 divides the course into 5 units, covering 57 listed topics. The unit-wise breakdown below is read from the GTU syllabus document for this subject code, so you can check what the course actually covers before deciding which papers to attempt.

Unit 1 Basics of Computer Systems

  • 1.1. Computer system block diagram, Concept of Hardware and Software
  • 1.2. CPU, Control Unit, Arithmetic logic Unit(ALU), Memory Unit, Power Unit and Interfacing Ports.
  • 1.3. Input Output unit: Monitor, keyboard, External Hard disk, Mouse Printers, Plotters, Scanner, Projectors, Webcam, Mic, etc.
  • 1.4. Operating system concepts, purpose and functions
  • 1.5. Operations of Windows and Linux
  • 1.5.1. Installation on PC / virtual box
  • 1.5.3. Files and Folder Operation
  • 1.5.4. Basic Terminal Commands
  • 1.5.5. Installation of various Application Software

  • 2.7. Introduction to data, Cell address, Excel Data Types, formatting, number, text and date Concept of hyperlink in Worksheet
  • 2.8. Understanding formulas, Operators and Common spreadsheet functions
  • 2.9. Types of graphics : Word art, auto shapes ,Images ,charts
  • 2.10. Concept of print area, margins, header, footer and other page setup options
  • 2.11. Overview of Spreadsheets and how to create Spreadsheets Using Professional Presentation
  • 2.12. Creating new Slides, Working with text boxes, fonts, tables, Layouts, themes, effects, background and Colours
  • 2.13. Selecting, deleting, moving, copying, resizing and arranging objects.
  • 2.14. Working with drawing tools, Applying shape or picture styles, Applying object borders, object fill, object effects, clip art collection and modifying clip art
  • 2.15. Embed a video, Link to a video, Size a video, Video playback options.
  • 2.16. Configuring a sound playback, Assigning sound to an object, Adding a digital music sound track, Transition effects and timings Using Gujarati IME
  • 2.17. Installation of Guajarati IME Software
  • 2.18. How to change language English to Gujarati
  • 2.19. Introduction about the Gujarati keyboards

  • 3.5. Computer and Peripheral sharing in LAN
  • 3.6. Remote Login
  • 3.6.1. Remote Desktop
  • 3.7. Data Transfer or sharing
  • 3.7.1. Using LAN
